## iPos Desktop Connect

##### Python API for [iPos Dekstop](https://inspirasi.biz/downloads) - The best desktop-based Point of Sales software.

### Currently Available Packages 🔌

| Package                                                                                                  | Description                                                                                                                      |
|----------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| [Iposconnect Dataframe](https://github.com/DeeloaSociety/iposconnect/tree/develop/iposconnect-dataframe) | API Wrapper uses [Ibis](https://ibis-project.org/) dataframe library, simplifying data transformation to Pandas, CSV, JSON, etc. |
| [Iposconnect ORM](https://github.com/DeeloaSociety/iposconnect/tree/develop/iposconnect-orm)             | API wrapper uses [SQLAlchemy](https://www.sqlalchemy.org/) is the Python SQL toolkit and Object Relational Mapper.               |

All the Iposconnect packages maintained are added here.
